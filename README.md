# Computational Crime Linkage Analysis

A Python-based research prototype investigating computational similarity measures for linking potentially related residential
burglary incidents.

## Project Status

Currently in development.

## Objectives

- Generate a synthetic dataset of residential burglary incidents.
- Implement and compare two computational similarity measures.
- Rank potentially related incidents.
- Evaluate linkage performance using known ground-truth relationships.

## Technologies

- Python
- pandas
- NumPy
- scikit-learn
- matplotlib
